# Security Policy

## Reporting a vulnerability

Report security issues privately via GitHub's
[Security Advisories](https://github.com/gabdevele/subhunt/security/advisories/new)
or by email. Please do not open a public issue for security reports.

Include a description, reproduction steps and the affected version. You can expect
an acknowledgement within a few days.

## Scope

subhunt is a reconnaissance tool. It does not exploit targets and only performs DNS
resolution and HTTP requests against hosts listed in HackerOne program scopes.
Only use it against programs you are authorized to test.
